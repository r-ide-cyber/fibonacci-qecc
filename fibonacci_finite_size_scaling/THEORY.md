## 入力検証と理論の適用を分ける理由

ユーザー指定の条件は、同じ組成、巡回非同値、相手の巡回同値類へ 1 回の隣接交換で移らないことです。本実装はこの定義を変更しません。

原論文 E.1 の seed 集合に対する条件は、交換後の巡回同値類が選んだ集合のどこにも属さないことです。したがって自己巡回同値類へ戻る交換も除外されます。この追加点は `self_swap_0`, `self_swap_1`, `paper_seed_condition` として別途診断し、入力の拒否には使いません。従来の `obtainable_by_one_adjacent_swap` は自己同値の入力で False を返すため、自己交換は明示的に検査します。

実装上の独立した確認例として、`0001001` と `0000011` はユーザーの相互交換条件を満たしますが、前者に自己同値の交換があります。整数カウントによる確認では n=1,2,3,4 の各 `f_n+1` 連続消失で KL 対角条件が成立しません。この pair に原論文の保証を無条件で適用できないことを示します。

## n=0 の扱い

`L_theory(0)` は式の値として 2 を返しますが、保証の適用は n>=1 に限定します。これは実装側の慎重な適用判断です。論文の復元証明の帰納法は n=1 から始まり、n=0 での局所頻度一致は長さ `f_1=1` に限られます。実際、`000111` と `010101` は原論文の seed 条件も満たしますが、n=0 の 2 連続消失は KL 対角条件を満たしません。n=0 は数値解析できますが、長さ 2 の理論保証を表示しません。

## 周期 seed と正規化

論文の状態式は比例記号で書かれており、seed の最小周期が N であるという仮定や一律の `1/sqrt(N)` はありません。これは周期 seed `010101` にも適用できます。

以下は正規化についての直接の代数的確認です。N 個の平行移動のうち異なる語が d 個なら、各語は N/d 回ずつ現れます。その和のノルムは `N/sqrt(d)` です。したがって正規化状態は

`|i_L> = (1/sqrt(d_i)) * sum_{x in distinct orbit O_i} |x>`

となります。本実装は異なる語だけを保存し、KL 対角ブロックの整数カウントをそれぞれの `d_i` で割ります。d_0 と d_1 が異なっても正しく比較します。seed `000111` と `010101` の系列では `d_0=N`, `d_1=N/3` です。

## 固定 window について導かれること

以下は原論文の保証と消失訂正の包含単調性からの推論です。原論文の seed 条件を満たす固定 pair では、n を増やすと `f_n+1` は発散します。したがって任意の固定 W は、有限の n 以降で `W <= L_theory(n)` になります。その時点で window 全体の消失とその全ての部分集合は訂正可能です。W=20,30,50 なら保証に初めて入る n はそれぞれ 7,8,9 です（上表の例）。

この条件下で、固定 W 内の任意消失が最終的に 100% になることは数値傾向だけではなく理論の帰結です。Notebook は保証に達する前の変化、実測の到達サイズ、保証との整合性を調べます。保証外であることは訂正不能を意味しません。`predicted_window_correctable` は保証内のみ True、保証外は欠損値です。全リングから固定個数を消失させる従来の実験とは消失配置の集合が異なり、今回の結果だけで従来の全リング任意消失性能の低下をすべて有限サイズ効果と断定することはできません。
